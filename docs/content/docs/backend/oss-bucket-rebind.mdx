# 一次性 OSS 换桶修复

后台「存储设置」中的「修复历史资源桶绑定」是临时维护入口，仅在已启用平台阿里云 OSS 时显示。有未保存配置时不可打开。

## 操作

1. 自行将旧桶文件完整复制到同 Endpoint 的新桶，保持完整对象路径不变。保存并启用新桶平台配置，确保凭据可读取文件。
2. 备份数据库及数据目录的 `.settings-key`，确认可恢复。暂停生成、上传、删除，等待后台任务结束；停止其他后端和 worker 实例，仅保留当前后端。工具不会自动备份、暂停任务或阻止普通业务写入。
3. 打开临时入口，填写旧桶名称，点击「检查」。新桶和凭据由后端读取，不另传密钥。
4. 核对新旧桶和检查数量，勾选备份、维护窗口确认，再点击「确认修复」。执行时重新检查；资源或配置变化须重新检查。
5. 成功后刷新资源页面，核对新域名与图片、视频、音频访问。本地和线上分别执行，不复制本地数据库到线上。

检查只读取数据库并对新桶发起 HEAD，可能产生少量 OSS 请求费用，不下载媒体。大小相同不代表内容哈希相同。整体检查超时停止，不做部分成功。

## 边界

- 只处理平台资源；个人存储、归属不明确、原文件未就绪或大小无效、衍生文件正在处理、衍生元数据缺失、删除任务或目标重复资源记录时整批停止，并提示具体原因。
- 允许带已就绪缩略图或播放版本信息的资源换桶，保留其元数据。当前播放副本仅用于本地存储，缩略图访问回退原文件；检查只对新桶原文件进行 HEAD 和大小核对，不猜测衍生对象路径，也不移动或删除本地播放副本。此功能不代表已验证新桶中的历史衍生文件；未来启用云端衍生访问时须另行补齐对应检查。
- 保留资源 ID、对象路径和用户归属，只更新桶、目标存储绑定、更新时间并清空旧 public_url。数据库事务失败整批回滚。
- 同进程拒绝同时检查/执行；这不是多实例在线迁移系统，必须遵守维护窗口要求。
- 不复制或删除云端文件，不替换画布或任务正文的手工外链，不清空浏览器缓存。新桶 CORS、权限、CDN 配置需另行核对。
- 请求中断不等于事务未提交，先重新「检查」。无旧桶资源不重复更新。恢复依赖事先备份，不会撤销云端文件变更。
- 不新增数据表或 Schema 48，不在启动时执行；已移除本轮 rebind-oss 命令。后续删除临时页面和接口不会撤销已保存的绑定。

## 接口

管理员专用 `POST /api/admin/settings/oss/rebind/check` 和 `/apply`，service 再校验权限。检查提交 `fromBucket`，返回计数及 `checkToken`；执行须提交该快照及 `backupConfirmed=true`、`maintenanceConfirmed=true`。具体合同见后端 OpenAPI。
